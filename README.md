# Blog Application

Простое веб-приложение для ведения блога с возможностью создания, просмотра и редактирования статей.

## 🌐 Демо

[https://blog-delta-beryl.vercel.app/](https://blog-delta-beryl.vercel.app/)

## 📋 Описание

Это одностраничное приложение (SPA) для управления блогом, которое позволяет пользователям:
- Просматривать список всех статей
- Читать полные версии статей
- Создавать новые публикации
- Редактировать существующие статьи
- Ставить лайки понравившимся постам

## 🛠 Технологии

- **React** 18.2.0 — библиотека для создания пользовательских интерфейсов
- **React Router DOM** 5.2.0 — навигация между страницами
- **Ant Design** 5.1.2 — UI-библиотека компонентов
- **React Hook Form** 7.43.5 — управление формами
- **Sass** — CSS-препроцессор
- **date-fns** — работа с датами
- **lodash** — утилиты для работы с данными

## 🚀 Установка и запуск

### Требования

- Node.js (рекомендуется версия 16+)
- npm или yarn

### Шаги установки

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd blog-app
```

2. Установите зависимости:
```bash
npm install
```

3. Запустите проект в режиме разработки:
```bash
npm start
```

Приложение будет доступно по адресу [http://localhost:3000](http://localhost:3000)
